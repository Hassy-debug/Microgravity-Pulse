## Reference Ranges
Status thresholds use general adult reference values, for example resting heart rate of 60–100 bpm and fasting blood sugar of 70–99 mg/dL. They are simplified for this prototype.

## Disclaimer
This is an educational prototype built during a hackathon. It is **not** medical advice and must not replace guidance from flight surgeons or medical professionals.
